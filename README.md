# Havenly — Real Estate Website Demo

A responsive, single-page luxury property website inspired by the supplied visual reference. Built with plain HTML, CSS, and JavaScript for easy previewing and GitHub Pages hosting.

## Included
- Editorial hero and property search controls
- About / agency trust section
- Featured property cards with responsive layout and save buttons
- Working location, property type, and price filters
- Testimonials, newsletter demo, and footer navigation
- Mobile menu and reduced-motion support

## Run locally
Open `index.html` in a browser. Property photography is loaded from Unsplash and web fonts from Google Fonts, so those visual assets need an internet connection.

## Demo notes
The search filters work on the three sample listings. Save buttons are local UI only. Contact links use a sample `havenly.example` address, and newsletter signup is a front-end demo; there is no CRM, backend, or transaction processing connected.
